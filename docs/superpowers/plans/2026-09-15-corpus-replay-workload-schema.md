# Corpus/Replay Workload Schema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Define the trace-workload document as one declarative schema (`corpus:`/`replay:`), validate it strictly at assemble time, and content-address the corpus cache key so two cells with identical corpus content share one build.

**Architecture:** A new `pipeline/lib/corpus_schema.py` holds the single definition of the document — legal keys, defaults, PipelineRun param names, coercions, and the set of known-but-not-yet-honored fields. Three consumers import it and cannot drift: `assemble_run._validate_workload` (rejects), `tekton.py` (emits), and one invariant test (asserts hashed-set == applied-set). `trace:` is replaced outright, not dual-supported.

**Tech Stack:** Python >= 3.12, PyYAML, pytest.

**Spec:** GitHub issue inference-sim/sim2real#901, plus five field-level rulings established during vetting (recorded under Global Constraints).

## Global Constraints

- Python >= 3.12 (`pyproject.toml` `requires-python`; enforced by `pipeline/__init__.py` and root `conftest.py`).
- CI must pass: `ruff check pipeline/ .claude/skills/ --select F`, then pytest with `--cov=pipeline --cov-fail-under=90`.
- **No backward compatibility with `trace:`.** No trace run has ever executed; there is no cached corpus, no trace results, and no shipped bundle. `trace:` is replaced. `transfer.yaml` `version:` stays **3** — synthetic descriptors do not change.
- **Synthetic (generative) cells must be byte-identical before and after.** Their param list, `workloadSpec` content, and validation path are untouched.
- **The invariant:** every field under `corpus:` is hashed **and** applied. Every field under `replay:` is applied and **not** hashed. A field that is neither applied nor rejected is a defect.
- **Five fields are REJECTED, not accepted**, because the `prepare-trace` Task at the pinned `tektonc-data-collection` submodule (`36e98be`) does not honor them:
  - `corpus.upstream.revision` — task support merged upstream (tektonc#67/#69) but **not pinned**; needs a submodule bump. Deferred to sim2real#905.
  - `corpus.upstream.format` — needs tektonc#68 (PR #71, open). Deferred to #905.
  - `corpus.reconstruct.max_think_time` — needs tektonc#68. Deferred to #905.
  - `corpus.select.partition_pct` — `TEST_PCT = 30` is a hardcoded Python constant in `prepare-trace.yaml`, not a param. Confirmed by the tektonc#68 author that #71 will not parameterize it.
  - `corpus.reconstruct.max_context` — no task-side or converter-side support exists anywhere. The field was invented in the issue's draft descriptor; admitting it would create the exact defect this change removes.
- **Rejecting `max_think_time` does NOT lift the converter's 15s clamp** — it makes it inexpressible. `blis convert otel --max-think-time` defaults to `15*time.Second` (`cmd/convert_otel.go:185`) and `prepare-trace` never passes the flag, so any corpus built before #905 still has its inter-round arrival gaps clamped at 15s. This is the correct interim state (better than hashed-and-ignored) but must be stated in the docs.
- **`shards` IS admitted**, at `corpus.upstream.shards`, deviating from the issue's literal schema block. The Task honors it (`SHARDS` env → `files[:shards]`), so by the invariant it must be admitted rather than dropped. Dropping it would silently change fetch scope from 39 shards to all.
- **`traceSpec` content is not parsed by anything.** `prepare-trace.yaml:91-92` tests only whether it is empty (empty ⇒ "generative workload, skipping"). Only its emptiness is load-bearing. Keep emitting it, with the `corpus:` mapping as content, and say so in a comment. Do not redesign it here — sim2real#900 collapses these params.

### Task 1: The schema module — tables, deferred-field messages, cache key

**Files:**
- Create: `pipeline/lib/corpus_schema.py`
- Test: `pipeline/tests/test_corpus_schema.py`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `CORPUS_FIELDS: dict[str, dict[str, _Field]]` — section (`upstream`/`select`/`reconstruct`) → field name → `_Field`.
  - `REPLAY_FIELDS: dict[str, _Field]` — field name → `_Field`.
  - `_Field` NamedTuple: `param: str`, `default: object | None`, `render: Callable[[object], str]`, `check: Callable[[object], bool]`, `describe: str`.
  - `DEFERRED_FIELDS: dict[str, str]` — dotted path (e.g. `"corpus.upstream.revision"`) → operator-facing reason.
  - `validate_corpus_document(doc: dict, where: str) -> None` — raises `errors.AssembleError`.
  - `corpus_cache_key(corpus: dict) -> str` — 12 hex chars.
  - `is_corpus_document(doc: dict) -> bool`.

  - `upstream.shards` → `traceShards`, default `39`, check non-bool `int` >= 0.
  - `select.partition` → `traceSplit`, default `"test"`, check in `{"test","train","all"}`.
  - `select.min_rounds` → `traceMinRounds`, default `2`, check non-bool `int` >= 1.
  - `select.dedup_by_conversation` → `traceDedupByConversation`, default `True`, check `bool`, render `"1"`/`"0"`.
  - `select.shuffle_seed` → `traceShuffleSeed`, default `42`, check non-bool `int`.
  - `reconstruct.context_growth` → `traceContextGrowth`, default `"accumulate"`, check in `{"accumulate","independent"}`.
- `REPLAY_FIELDS`: `concurrent_sessions` → `concurrentSessions`, no default (**required**), non-bool `int` >= 1; `total_sessions` → `totalSessions`, no default (**required**), non-bool `int` >= 0.
- `DEFERRED_FIELDS` — the five dotted paths with the reasons from Global Constraints. Each message must name the blocking issue so an operator can act.
- `is_corpus_document(doc)` → `isinstance(doc.get("corpus"), dict) and bool(doc["corpus"])`.
- `validate_corpus_document(doc, where)`:
  1. Top-level keys must be a subset of `{"corpus", "replay", "workload_name"}`. If `clients` or `cohorts` is present, raise the "exactly one kind" message naming both. Any other extra key raises an unknown-top-level-key error listing the legal set.
  2. `corpus` sections must be a subset of `CORPUS_FIELDS` keys; each present section must be a mapping.
  3. Within each section: a key in `DEFERRED_FIELDS` raises that field's specific reason (checked **before** the unknown-key branch, and the message must not contain the word "unknown"); a key in neither table raises unknown-key listing the section's legal fields.
  4. `replay` must be present and a mapping; keys subset of `REPLAY_FIELDS`; both required fields present and passing `check`.
  5. Required `corpus` fields present and passing `check`; optional fields, when present, passing `check`.
  6. Every failure raises `AssembleError` prefixed with `where` and the dotted path.
- `corpus_cache_key(corpus)` → `hashlib.sha256(json.dumps(corpus, sort_keys=True, separators=(",",":")).encode()).hexdigest()[:12]`. Hashes the mapping **as given** — no name, no `replay`, no default-filling (a document is validated before hashing, so only legal keys can be present; filling defaults would make an explicit `shards: 39` hash differently from an omitted one, which is a distinction without a difference but also not one worth introducing quietly — document that the hash is over the *written* document).
